# Рекомендации по улучшению тёмной темы

## Контрастность текста и элементов

-   **Основной фон** -- использовать тёмно-серые тона вместо чистого
    чёрного. Например, Material Design рекомендует `#121212` в качестве
    основного цвета поверхности. Это даёт умеренный контраст: светлый
    текст на тёмно-сером фоне не слишком «режет глаза», но остаётся
    читаемым.
-   **Текст** -- главный текст делать практически белым (например,
    `#F5F5F5` или `#EFEFEF`), а второстепенный -- серым (например,
    `#A0A0A0` или `#B0B0B0`), чтобы визуально разграничивать иерархию.
-   **Иконки и кнопки** -- пусть будут светлыми или десатурированными,
    чтобы чётко выделяться на тёмном фоне. Держите между ними небольшой
    контраст (например, тонкие линии или светлая граница), иначе
    элементы «сливаться».
-   **Проверка доступности** -- убедитесь, что контраст текста с фоном
    не опускается ниже рекомендуемых значений. Используйте
    онлайн-инструменты (например, [WebAIM Color Contrast
    Checker](https://webaim.org/resources/contrastchecker)) для
    автоматической проверки сочетаний цветов в интерфейсе.

## Лучшие практики настройки контрастов в UI

-   **Ограниченное количество акцентов**. Используйте не более 2--3
    акцентных цветов. Большинство пространства оставьте для нейтральных
    тёмных поверхностей.
-   **Чёткие разделители**. Между разными компонентами интерфейса
    делайте небольшие отличия фонов или бордеров.
-   **Повышение удобочитаемости**. Обеспечьте достаточный интервал и
    размеры шрифта для мелкого текста.
-   **Тестирование**. Проверяйте интерфейс в разных условиях освещения и
    на разных экранах.

## Рекомендованные значения контрастности (WCAG)

-   **Уровень AA (минимум)**: для текста любого размера -- контраст
    ≥ 4.5:1. Крупный текст допускает ≥ 3:1.
-   **Уровень AAA (повышенный)**: для обычного текста -- ≥ 7:1, для
    крупного -- ≥ 4.5:1.
-   **UI-элементы (нетекстовый контент)**: кнопки, иконки, графические
    маркеры -- контраст ≥ 3:1 с соседними цветами.

## Примеры стилей (CSS / Tailwind)

``` css
/* Пример CSS-классов */
.bg-dark         { background-color: #121212; }
.surface         { background-color: #1E1E1E; }
.text-primary    { color: #F5F5F5; }
.text-secondary  { color: #A0A0A0; }
.border-light    { border-color: #2B2B2B; }
```

``` html
<!-- Пример с Tailwind CSS -->
<h1 class="bg-gray-900 text-white">Заголовок</h1>
<p class="text-gray-400">Второстепенный текст...</p>
<input type="text" class="bg-gray-800 border border-gray-700 text-gray-100" placeholder="Поле ввода" />
```

## Рекомендуемые иконки и шрифты

-   **Иконки**: outline или плоские белые/светло-серые, например
    Heroicons, Material Icons (outline), FontAwesome.
-   **Шрифты**: без засечек (Roboto, Open Sans, Inter, Helvetica, PT
    Sans). Избегать слишком тонких начертаний.
