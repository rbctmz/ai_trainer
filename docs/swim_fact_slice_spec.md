## Change Class

Class A для #765 из-за влияния новых фактических свидетельств на разбор
тренировки. Этот срез добавляет только совместимое поле. Бюджет ревью
0 из 2. Режим запроса ручной. Принятие ревью ожидается.

## Scope

Новые нормализованные интервалы Intervals.icu, его группы и круги Garmin
сохраняют конечное неотрицательное provider distance как distance_meters.
Нулевой отрезок с явно заданной дистанцией сохраняет 0. Отсутствие поля,
bool, отрицательное, нечисловое и бесконечное значение дают null.
Дробные метры из источника сохраняются. Это точность числового поля
провайдера. Степень покрытия заплыва определяется в срезе сопоставления.

## Non-goals

Пересчёт старого кэша, изменения TSS, новая загрузка данных из аккаунта,
автоматические назначения темпа и изменение изображения карточки
остаются за пределами этого среза.

## Definition of Done and Public Contracts

Адаптеры, кэш и существующий ответ карточки сохраняют исходные метры.
Округлённое distance_km сохраняет прежнюю точность для валидных входов.
TypeScript и извлечённый контракт описывают необязательное
distance_meters: number | null. API совместим с записями без этого поля.
Таблицы, конфигурация, CLI и связи активностей остаются прежними.

## Failure, Reset, Rollback, Idempotency

Невалидное расстояние оставляет оба поля null, остальной отрезок читается.
Старую запись отдаём как есть через существующий кэш. Повторная запись
обновляет существующий JSON под тем же ID. Дополнительных таблиц, курсоров
и артефактов сброса нет. Откат коммита восстанавливает предыдущую проекцию.
Текущая стратегия выбора источника и поведение при сбое провайдера сохраняются.

## State Boundaries and Identity

Дистанция берётся из конкретного исходного отрезка. Garmin и Intervals.icu
сохраняют собственные списки. Привязка к канонической активности, обновление
по ID и поведение при параллельных запросах остаются в существующем сервисе.

| Источник и данные | Ожидаемый результат |
| --- | --- |
| Garmin lap или Intervals.icu interval/group, 25/75 м | 25/75 в distance_meters |
| Явные 0 м или дробное значение | Число сохранено |
| Отсутствие, bool, минус, NaN, Infinity | null |
| Офлайн, legacy-кэш с 0.03 км | Старая строка без автоматически восстановленных метров |
| Два источника для одного ID | Исходные назначения и списки сохранены |

## ASR / ADR Traceability

ASR-REL-2 допускает недостаток данных без падения. ASR-PERF-3 сохраняет
существующий кэш и бюджет provider I/O. ASR-MOD-2 требует явный контракт
карточки. ADR 0008 сохраняет идентичность активности и независимость
источников. ADR 0001 закрепляет общий Python-адаптер и web-контракт.
