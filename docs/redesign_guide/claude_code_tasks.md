## 📊 Статусы задач

- 🔴 **TODO** - Новая задача для Claude Code
- 🟡 **IN PROGRESS** - Claude Code работает над задачей
- 🟢 **DONE** - Задача выполнена
- 🔵 **REVIEWED** - Проверено и принято
- ⚫ **BLOCKED** - Заблокировано, нужна помощь

## 💡 Инструкции для Claude Code

### Как работать с этим файлом:

1. **Начало работы:**
   - Открой этот файл
   - Найди первую задачу в секции TODO
   - Переместе её в IN PROGRESS
   - Начни выполнение

2. **После выполнения:**
   - Перемести задачу в DONE
   - Добавь комментарий что сделано
   - Обнови лог выполнения

3. **При проблемах:**
   - Перемести в BLOCKED
   - Опиши проблему
   - Жди помощи

### Пример записи после выполнения:
```markdown
### 🟢 DONE
- [x] Объединить AI-коучинг функции в табированный интерфейс
  - Создано 5 табов для разных AI функций
  - Добавлены быстрые вопросы
  - Файлы: app.py (строки 450-650)
  - Время: 15 минут
```
