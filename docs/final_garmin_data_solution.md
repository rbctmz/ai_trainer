## 🔍 Установленные причины

### 1. **Ограничения API библиотеки `garminconnect`**
- Неофициальная библиотека имеет ограниченный доступ
- Данные сна могут требовать специальной авторизации
- Статус тренированности может быть Premium-функцией

### 2. **Настройки Garmin Connect**
- Возможные ограничения приватности
- Требования к типу устройства (не все поддерживают сон)
- Необходимость Premium подписки для статуса тренированности
