# 🦙 Руководство по настройке Ollama для AI Коучинга

## Обзор
Ollama позволяет запускать большие языковые модели локально на вашем компьютере. Это идеально для AI коучинга без внешних API и ограничений.

## ✅ Преимущества Ollama
- 🔒 **Полная конфиденциальность** - данные не покидают ваш компьютер
- 💰 **Бесплатно** - никаких API ключей и лимитов
- ⚡ **Быстрые ответы** - нет задержек сети
- 🌍 **Офлайн работа** - не нужен интернет

## 📋 Что уже настроено

У вас Ollama уже работает! Проверим статус:

## 🎯 Рекомендуемые модели для AI коучинга

### Для быстрого коучинга:
- **gemma3:4b** (3.3GB) - хорошее качество, умеренная скорость
- **llama3.2:latest** (2GB) - компактная, хорошая для простых задач

### Для качественного коучинга:
- **llama3.1:8b** (4.9GB) - лучшее качество, требует больше RAM
- **deepseek-r1:7b** (4.7GB) - отличная для аналитических задач

### Для экспериментов:
- **tinyllama:latest** (637MB) - самая быстрая, базовое качество

## ⚙️ Текущие настройки

В файле `.env`:
```env
# Ollama локальный AI
OLLAMA_HOST=http://localhost:11434
OLLAMA_MODEL=gemma3:4b
DEFAULT_AI_PROVIDER=ollama
```

## 🔧 Решение проблем

### Модель слишком большая
```bash
# Проверьте доступную память
free -h

# Переключитесь на меньшую модель
# В .env файле измените:
OLLAMA_MODEL=gemma3:4b  # Вместо llama3.1:8b
```

### Медленные ответы
```bash
# Используйте более быструю модель
OLLAMA_MODEL=llama3.2:latest

# Или самую быструю
OLLAMA_MODEL=tinyllama:latest
```

### Ollama не отвечает
```bash
# Перезапустите сервис
ollama serve

# Проверьте статус
curl http://localhost:11434/api/tags
```
