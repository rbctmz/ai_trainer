# Авторское плавание из календаря на Garmin

В календаре у назначенной тренировки появляется действие «Доставка на Garmin».
Панель показывает дату, версию, бассейн и порядок шагов до подтверждения.
Фиксированные паузы и паузы по Lap видны в списке. После подтверждения
квитанция сообщает наблюдённый результат Intervals.icu. Проверка на часах
остаётся отдельным шагом.

Снимки получены в Chromium на анонимной программе V2 и тестовом транспорте,
через настоящий API и временную SQLite. Мобильный сценарий использует 390 px
и тёмную тему. Широкий использует 1280 px и светлую. Проверены фокус панели и
предпросмотра, возврат фокуса после закрытия, отсутствие горизонтального
переполнения и повторное чтение квитанции после перезагрузки.
