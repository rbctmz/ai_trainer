# Календарь тренировок тренера

Синтетическая программа `example_program` и временный цикл из семи дней.
Chromium проверил одну цепочку в тёмной теме на 390 px и в светлой на 1280 px.

- `calendar-preview-*.png` показывает дату, точную версию, раскрытые шаги,
  неизвестную нагрузку и действие подтверждения.
- `calendar-week-*.png` показывает тренировку в её календарном дне и пометку
  о TSS рядом с недельным графиком.

Снимки иллюстрируют изолированную приёмку. Сам тест проверяет отсутствие записи
при предпросмотре, фокус, фактическое сохранение, перенос и возврат выбранной
версии. Снимки не являются измерением всего интерфейса.

`metadata.json` указывает SHA-256 исходников браузерной реализации и файлов
снимков. При сравнении используйте хеши, поскольку тест запущен до commit.
