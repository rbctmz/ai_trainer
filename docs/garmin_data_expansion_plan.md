# План расширения данных Garmin Connect

### ✅ Активности
- Основные метрики (дистанция, время, пульс, мощность)

- Набор высоты, калории

### ✅ HRV данные
- RMSSD

### ✅ Профиль пользователя
- Основная информация

## 🚀 Доступные данные для расширения

### 1. 😴 Детальные данные сна
**Текущее:** не используется  
**Доступно через:** `get_sleep_data(date)`
```python
# Новые метрики:
- Общее время сна
- Глубокий сон
- Лёгкий сон
- REM сон
- Пробуждения
- Качество сна (индекс)
- Время засыпания/пробуждения
```

**Польза для тренировок:**
- Корреляция качества сна с восстановлением
- Планирование интенсивности по качеству сна
- Предупреждение перетренированности
- Оптимизация времени тренировок

### 2. 🫀 Расширенные данные пульса
**Текущее:** базовые метрики в активностях  
**Доступно через:** `get_heart_rate(date)`, `get_resting_heart_rate(date)`
```python
# Новые метрики:
- Пульс покоя (ежедневный)
- Пульсовые зоны (детальное время в зонах)
- Максимальный пульс за день
- Вариабельность пульса в течение дня
- Восстановление пульса после нагрузки
```

**Польза для тренировок:**
- Более точные пульсовые зоны
- Мониторинг перетренированности (повышенный пульс покоя)
- Анализ эффективности восстановления
- Персонализация зон интенсивности

### 3. 💨 Данные дыхания
**Текущее:** не используется  
**Доступно через:** `get_respiration(date)`
```python
# Новые метрики:
- Частота дыхания в покое
- Частота дыхания во время активности
- Вариабельность дыхания
- Аномалии дыхания
```

**Польза для тренировок:**
- Индикатор стресса и восстановления
- Оценка эффективности дыхательных техник
- Ранний индикатор заболевания или перетренированности

### 4. 🩸 SpO2 (кислород в крови)
**Текущее:** не используется  
**Доступно через:** `get_spo2_data(date)`
```python
# Новые метрики:
- Сатурация кислорода
- Ночные измерения SpO2
- Тренды насыщения
- Высотная акклиматизация
```

**Польза для тренировок:**
- Мониторинг высотной подготовки
- Оценка эффективности дыхательной системы
- Выявление проблем с восстановлением
- Контроль перетренированности

### 5. 🎯 Статус тренированности
**Текущее:** не используется  
**Доступно через:** `get_training_status()`, `get_training_readiness()`
```python
# Новые метрики:
- VO2 max (оценка)
- Фитнес-возраст
- Тренировочная нагрузка (автоматическая от Garmin)
- Баланс нагрузки
- Состояние тренированности
- Готовность к тренировке
- Рекомендации по восстановлению
```

**Польза для тренировок:**
- Профессиональные метрики готовности
- Сравнение с алгоритмами Garmin
- Комплексная оценка состояния
- Автоматические рекомендации

### 6. 🏃‍♂️ Расширенные метрики активности

**Доступно через:** детальные данные активности

**Польза для тренировок:**
- Техническая оценка бега/езды
- Оптимизация эффективности движений
- Персонализированные зоны мощности
- Детальный анализ техники

### 7. 🏔️ Данные по высоте и акклиматизации
**Текущее:** набор высоты  
**Доступно через:** расширенные данные активности

**Польза для тренировок:**

### 8. 📱 Ежедневная активность

## 🛠️ Техническая реализация

### Структура базы данных
```sql
-- Новые таблицы
CREATE TABLE sleep_data (
    date DATE PRIMARY KEY,
    total_sleep_minutes INTEGER,
    deep_sleep_minutes INTEGER,
    light_sleep_minutes INTEGER,
    rem_sleep_minutes INTEGER,
    awakenings_count INTEGER,
    sleep_score REAL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE daily_health (
    date DATE PRIMARY KEY,
    resting_hr INTEGER,
    steps INTEGER,
    calories_burned INTEGER,
    active_minutes INTEGER,
    spo2_avg REAL,
    respiration_avg REAL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE training_status (
    date DATE PRIMARY KEY,
    vo2_max REAL,
    fitness_age INTEGER,
    training_load REAL,
    training_status TEXT,
    training_readiness REAL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
